# AtvfinalLV
Atividade final do curso "Introdução ao R com dados de saúde".

Durante quatro aulas, o curso "Introdução ao R com dados de saúde", ministrado pelo professor Raphael Saldanha na Fundação Oswaldo Cruz, proporcionou o conhecimento básico e aplicado da linguagem R
para trabalhar com dados de saúde pública, objetivando o entendimento da análise e filtragem de dados, criação de funções, tabelas, gráficos e mapas.

Para a atividade final, o objetivo era de apresentar uma rotina de trabalho envolvendo algum dado de preferência envolvendo saúde e apresentar os resultados obtidos em apresentação oral.
A partir de dados do SINAN de Leishmaniose Visceral do Microdatasus, os dados extraídos foram selecionados de acordo com o período de tempo de 2019 a 2025 e de estado do Rio de Janeiro
para a criação de tabelas e gráficos estatísticos, além do mapa da distribuição dos casos no estado no ano de 2023, tendo em vista que foi o de maior incidência de casos.
